# Homepage Responsive Optimization

## Scope

- Responsive header and mobile navigation.
- Constraint-based hero geometry instead of viewport-percentage positioning.
- Responsive Spline stage sizing.
- Responsive floating hero icons and CTAs.
- Consistent homepage container and card spacing.
- Connected mobile process timeline.
- Global overflow, media, focus, and reduced-motion safety rules.

## Validation

The branch was compared against `main` and contains only the intended responsive homepage files. A local browser/device matrix is still recommended before production release, especially for the external Spline scene across low-memory mobile devices.
